
현대 AI 모델 대부분은 딥러닝 모델.
특정 분야에서 인간 전문가를 상회하는 성능을 달성함.

딥러닝 - CNN(이미지, 동영상 등 정보처리) RNN(시계열 정보 처리) Transformer(텍스트 정보 처리 ex ChatGPT, Gemini)


딥러닝 : 입/출력 사이에 존재하는 레이어가 깊게 쌓여있는 모델. 수많은 레이어를 통과하며 데이터가 점진적으로 처리. 깊은 모델일수록 추상적인 문제도 처리가능, 복잡한 문제 처리가능.

딥러닝의 구조는 모델이 어떤 기능을 수행하냐에 따라 달라짐.
CNN : 이미지와 관련된 일이라 convolution, subsampling 활용
Transformer : 주로 텍스트 관련된 일

딥러닝의 구조
크게 3가지로 나눔

1. 입력층 : 입력 데이터를 받는 층
2. 은닉층 : 데이터 내부의 특징을 학습 및 추출하는 층 (중요!)
3. 출력층 : 모델의 최종 결과를 도출하는 층

레이어 : 특징 추출

각 레이어를 지날때마다 데이터에서 유의미한 특징을 추출.
단계별로 나누어 처리하고 핵심만 점점 남겨짐.
일종의 정보 필터링

ex) CNN 
초기 레이어 : 단순한 선, 색상, 패턴 등 Low-Level 특징을 인식
후반 레이어 : 눈, 코, 입 같은 복잡한 형태의 High-Level 특징을 인식

Transformer
레이어를 거치며 단어 간의 관계를 파악.
단순 단어의 나열에서 문맥의 의미까지 파악.



레이어 내부의 작동 원리


레이어의 구성 : 퍼셉트론
각 레이어는 수많은 퍼셉트론으로 이루어져있음. 신경망의 기본구성요소.
각 퍼셉트론들의 연결 강도를 가중치 라고 함.
입력된 정보는 가중치에 따라 선별 및 가공되는 과정을 거침.

활성화 함수
가중치를 활요해 정보를 단순히 더하는 것만으로는 복잡한 문제를 해결할 수 없음. 활성화 함수는 입력된 정보에 비선형성을 부여해 복잡한 데이터를 이해할 수 있게 함.
ex) ReLU : 음수는 0으로, 양수는 그대로 통과시키는 함수. 유의미한 신호만 전달하는 스위치 역할을 함. 구조가 단순하면서도 효과적이기 때문에 다양한 모델에서 널리 사용됨.

입력층 : 모델의 입력.
인간이 이해 가능한 데이터 형태를 AI가 이해할 수 있는 형태로 바꿔주는 첫번째 단계.

은닉층 : 입력층과 출력층 사이에 위치한 모든 레이어. 은닉층이 깊게 쌓인 구조를 딥러닝이라고 부르게 됨. 각 은닉층들은 이전 레이어들로부터 입력값을 받고, 가중치를 가해 곱하고 더한 후 활성화 함수를 지나 다음 레이어로 계산된 값을 전달하게 됨. 모델의 사고과정에 해당함.
특징추출과 정보조합이 이루어짐.

출력층 : 판단 결과를 정리함. 여러 은닉층을 거쳐 마지막으로 나온 값 그대로를 '로짓' 이라고 부름. 로짓은 범위가 제각각이고 인간이 직관적으로 이해할 수 없는 상태. 모델이 어떤 판단을 한것인지 정리하고 변환하는 과정 필요.

ex) Softmax 함수를 활용한 확률 변환.
출력층 내 모든 값의 합이 1이 되도록 변환시켜주는 함수. 로짓 숫자 값을 확률 형태로 바꾸어 어떤 출력 결과가 유력한지 비교 가능하게 함.


실습 - 신경망이 코드로 어떻게 정의되는지, 그 결과로 어떤 레이어 구조가 만들어지는지.

Pytorch - 신경망을 모듈 단위로 직관적으로 설계할 수 있게 해줌.
레이어 구조와 순전파 과정을 명확하게 파악가능.
torch 라이브러리 - 각 레이어별 출력 크기와 파라미터 수를 표 형태로 요약해줌.
