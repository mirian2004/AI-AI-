03차시 - 패턴을 본다는 것: 확률과 특징 추출의 직관



1. 확률 기반 패턴 인식의 원리

AI 학습의 본질: 암기 VS 패턴
AI는 데이터베이스처럼 문제의 정답을 통째로 암기하는 것이 아님.
데이터 내부에 존재하는 규칙성과 확률적 패턴을 학습하여 새로운 문제에 적용함

데이터베이스
입력: 정보를 그대로 저장
출력: 검색해서 일치하는 정보를 출력

AI 모델
입력: 모델의 파라미터에 저장
출력: 입력에 따라 확률에 기반해 출력

패턴의 의미
AI가 학습하는 패턴은 데이터에서 반복적으로 나타나는 특징들의 조합임
개별 데이터 하나하나보다, 여러 데이터에서 공통적으로 나타나는 경향성이 중요함.

데이터 양과 패턴 학습의 관계
데이터가 많을수록 패턴의 통계적 규칙성이 뚜렷해짐
대규모 데이터를 학습할수록 예외 상황을 포함한 일반적인 패턴을 잘 찾아 정확도가 높아짐

확률적 출력의 개념
AI는 하나의 정답을 단정적으로 선택하지 않음
여러 가능한 결과 중, 데이터 패턴에 기반해 각각의 가능성을 확률로 표현함
이러한 확률적 판단을 통해 가장 그럴듯한 결과를 선택함

확률적 출력의 예: 분류(Classification)
분류 모델은 입력 데이터에 대해 특정 출력이 나타날 확률을 계산함.
예측 라벨을 정하기 위해서는 확률이 임계값을 넘는지 확인함.

확률적 출력의 예: 생성(Geeration)
생성형 AI(GenAI) 또한 확률을 기반으로 다음 단어나 픽셀을 생성함.
주어진 조건 하에, 가장 확률이 높은 결과물을 만들어내도록 학습함
ex) 디퓨전 모델, LLM



2. 데이터 형태에 따른 패턴의 차이

데이터 타입별 패턴 인식 전략
모든 데이터가 같은 방식으로 처리되지 않음
텍스트, 이미지, 오디오 등 데이터의 종류에 따라 학습해야할 패턴이 달라짐

텍스트 데이터의 패턴: 시간과 문맥
텍스트는 단어의 등장 순서 뿐만 아니라 앞뒤 문맥이 중요함
이를 위해 순서를 고려하여 단어 간의 관계를 파악해야 함

이미지 데이터의 패턴: 공간과 배치
이미지는 픽셀 값들의 공간적 배치가 중요함
인접한 픽셀 간의 색상변화, 경계선, 질감 등 공간적 특징을 파악해야 함

기타 데이터의 패턴
오디오 - 파형의 진폭과 주파수 변화 패턴
비디오 및 3D - 2D 공간 정보에 추가적인 축이 더해진 복합 패턴
시계열 - 심전도, 주식, 날씨 등 시간 흐름에 따른 등락 패턴

이미지 데이터와 텍스트 데이터의 패턴 유사성
최근 이미지 데이터의 패턴을 학습하기 위해, 텍스트 데이터의 패턴을 학습하는 과정에서 사용한 방식을 도입하기도 함



3. AI가 특징을 추출하는 과정

특징 추출(Feature Extract)의 정의
입력된 데이터에서 불필요한 정보를 걸러내고 핵심 정보만 남기는 과정을 의미함.
원본 데이터는 정보량이 많고 복잡하기 때문에, AI는 특징을 통해 패턴을 학습하게 됨.

특징 추출과 모델 구조의 연관성
모델의 구조에 따라 특징을 추출하는 방식이 달라짐.
모델 구조는 어떤 정보를 중요하게 볼지 결정하는 틀의 역할을 함
텍스트 모델 - 문장 내 단어들 사이의 중요도를 계산하여, 서로 어떤 단어가 강하게 연결되는지를 통해 특징을 파악함
이미지 모델 - 작은 영역을 반복적으로 살펴보며, 윤곽선, 모양과 같은 공간적 특징을 단계적으로 추출함.

특징 추출의 실패 사례
잘못된 특징 학습은 잘못된 판단으로 이어질 수 있음
ex) 눈밭의 늑대만 있는 데이터로 학습한 경우, AI는 늑대라는 동물이 아니라 하얀 배경을 늑대의 특징으로 학습할 수 있음
