04차시 - 확률 기반 출력 해석: Softmax, 엔트로피, 크로스엔트로피



1. 확률로 변한하는 Softmax의 역할

Softmax 함수 공식 :  Softmax(x) = exp(x) / ∑exp(x)
입력값이 음수라도 양수로 만들어줌
큰 값은 더 크게, 작은 값은 더 작게하여 값들 간의 차이를 확연하게 해줌

확률 분포의 생성
이를 통해 만들어진 확률 분포를 통해 AI는 최종 결과를 예측함.

확률을 조절하는 온도: Temperature
Softmax 함수에는 Temperature(T) 라는 요소를 적용할 수 있음.
모델이 스스로 학습하지 않고 사람이 직접 설정해야 하는 값을 하이퍼파라미터라고 함.

Temperature에 따른 분포 변화
Temperature를 조절함으로써 분포의 형태를 바꿀 수 있음.
-Low Temperature(T->0) : 분포가 뾰족해짐
-Low Temperature(T>1) : 분포가 평평해짐



2. 엔트로피: 불확실성을 측정하는 통계적 개념

엔트로피의 정의
엔트로피는 정보이론에서 기인한 개념으로, 불확실성의 크기를 나타냄.
즉, 예측이 어려울수록 혹은 무질서할수록 엔트로피 값이 높음.

엔트로피의 직관적 이해
결과가 뻔할수록 예측이 쉬우므로 엔트로피가 낮음
결과를 알 수 없을수록 예측이 어려우므로 엔트로피 높음.

엔트로피 계산
실제 엔트로피를 구하는 식: H(x) = -∑p(xi)logp(xi)
>확률분포가 고르면 값이 커지고, 한쪽으로 쏠리면 값이 낮게 나옴

엔트로피와 Temperature의 관계
Temperature가 낮을수록 모델의 분포는 더 뾰족해짐
그로인해 엔트로피는 낮아지고(모델이 정답을 확신) 모델은 확실한 출력만 생성하게 됨.
-Temperature 낮음 > 뾰족 > 엔트로피 낮음
-Temperature 높음 > 평평 > 엔트로피 높음



3. 크로스엔트로피: 정답과의 불확실성 거리 계산

엔트로피를 모델 학습에 사용하지 않는 이유
엔트로피는 모델이 예측한 확률에 대한 관계만 있고 실제 정답은 고려하지 않음. (엔트로피는 모델의 확신 정도만 알려주지 예측한 것이 정답인지 아닌지는 알려주지 않음)
ex) 예측한 분포는 두번째 클래스가 정답이라고 확신 -> 엔트로피 낮음
그런데 정답은 네번쨰 클래스일 수 있음 -> 예측 실패  

크로스엔트로피의 정의
예측한 확률 분포(Q)와 실제 정답 분포(P) 간의 차이를 계산하는 공식
두 확률 분포가 얼마나 다른지를 측정하는 척도로 사용됨

크로스엔트로피 계산
실제 크로스엔트로피를 구하는 식: H(P,Q) = -∑P(i)logQ(i)
정답 분포는 정답 클래스만 1이고 나머지는 0인 원-핫 인코딩으로 주어짐
ex) 이진 분류 모델

이진 크로스엔트로피(Binary Cross Entropy; BCE)
정답(y)이 0 아니면 1인 이진분포를 고려하는 크로스엔트로피를 의미함.
모델의 예측(y^)이 확률값으로 나올때 아래 공식을 이용해 BCE를 계산함.
BCE(y,y^) = -(ylog(y^) + (1-y)log(1-y^))

크로스엔트로피의 벌점 부과 메커니즘
오답을 높은 확률로 확신하는 경우 가장 큰 페널티를 받음
