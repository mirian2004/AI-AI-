05차시 - Loss와 AI의 학습목표 이해



1. 오답 수정으로서의 학습

학습의 정의 : 오차 줄이기
AI는 처음에는 정답을 모르는 상태에서 무작위로 예측.
학습 과정에서 예측 결과와 실제 정답을 비교하여 틀린 부분을 수정해나감.


AI 학습의 파이프라인
AI 하급은 아래 세가지 단계를 반복적으로 진행함.

1. AI 모델의 예측
(오차 계산)
2. 정답 확인
(모델 수정)
3. 모델 파라미터 수정(핵심***)
(학습 반복)
다시 1번으로 돌아가 반복



2. 손실 함수의 역할

손실 함수의 정의
모델이 얼마나 틀렸는지를 주관적 느낌이 아닌 숫자로 나타내는 함수.
학습 과정에서 현재 모델의 성능을 평가하는 지표로 사용됨.

문제 유형에 따른 손실 함수 선택
문제의 종류에 따라 오차인 손실 함수를 계산하는 방식이 달라짐.

분류 - 크로스엔트로피
회귀 및 예측 - MSE, MAE
생성 - 마스크 예측 손실, 분포 차이 손실 등

ex) 분류 문제
분류 문제의 경우, 주어지 데이터에 대해서 정답 라벨이 존재함. 모델은 삭습을 통해 정답 라벨과 예측한 라벨의 차이를 줄이도록 학습함.

분류 문제는 크로스엔트로피를 손실 함수로 사용함. 크로스엔트로피는 예측 분포와 정답 분포 사이의 차이를 계산.

ex) 회귀 문제
회귀 문제의 경우, 두 데이터 분포를 가장 잘 설명하는 관계식을 찾아야함.
모델은 학습을 통해 예측한 관계식이 실제 관계식과 차이가 작아지도록 학습함.

회귀 문제는 MSE를 손실함수로 사용함. MSE는 예측값과 정답 사이의 거리의 제곱을 평균 낸 값이다.

AI 학습의 궁극적 목표 : 손실 최소화
학습이란 결국 이 손실값을 최소화하여 0에 최대한 가깝게 만드는 과정임.
오차가 0이 된다는 것은 예측이 정답과 완벽하게 일치함을 의미함.
이러한 모델을 최적 모델이라고 함.



3. 반복 학습과 오차의 감소

반복 학습의 필요성
실제 AI 모델을 학습할 떄, 모델의 파라미터를 한번에 수정하지 않음.
AI가 방대한 데이터의 패턴을 익히기 이ㅜ해 학습 데이터를 여러 번 반복해서 봐야함.

에폭(Epoch)의 정의
에폭은 모델이 전체 학습 데이터를 한 번 학습한 과정을 의미함.

모델 체크포인트와 에폭
에폭은 학습 양을 의미하므로 같은 모델 구조를 가져도 에폭에 따라 성능이 달라짐.
에폭에 따라 모델의 파라미터를 저장한 체크포인트가 달라짐.

반복에 따른 Loss 변화
초기 AI 모델은 무작위로 예측하기 때문에 적은 epoch에서는 Loss가 높고 성능이 낮다. Epoch가 늘어나면서 모델은 학습 데이터에 대한 Loss가 줄어들며 성능이 높아짐. 

학습 완료의 기준
모델 학습을 무조건 많이 반복한다고 좋은 것은 아님.
Loss가 더 이상 줄어들지 않고 평평해지는 구간에 도달하여 수렴하면 학습을 멈춤.
