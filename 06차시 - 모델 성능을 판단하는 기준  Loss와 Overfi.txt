06차시 - 모델 성능을 판단하는 기준 : Loss와 Overfitting



1. Epoch에 따른 Loss의 변화

학습 곡선의 시간 별 분석
초기에 급격히 낮아지는 이유는 초기에 쉬운 패턴(저차원적 요소)을 빠르게 학습하기 때문. 
이후에 Loss 감소가 더뎌지는 이유는 학습하기 어려운 패턴만 남았기 떄문.

모델의 실제 성능 비교
학습 데이터에 대한 Loss가 작다고 다른 데이터에서도 Loss가 작다고 보장할 수 없음. 
진짜 성능이 좋아진 것인지 확인하려면 학습 데이터와 다른 비교대상이 필요함.



2. 과소적합(Underfitting) & 과적합(Overfitting)

데이터의 3단 분리: Train/Val/Test
AI 학습 시 전체 데이터를 아래와 같이 세 종류로 나눔
Training set : 학습용 - 모델이 실제로 학습하는 데이터
Validation set: 검증용 - 학습 중 평가만 하는 데이터
Test set: 최종 평가용 - 학습 후 딱 한 번 사용하는 데이터

검증 데이터(Validation set)의 역할
학습 데이터의 Loss가 줄어드는 것은 당연한 현상임
학습에 쓰지 않은 Validation 데이터의 Loss 변화가 모델의 일반화 성능을 대변함.

Loss 곡선으로 보는 상태 진단법
학습 데이터와 검증 데이터의 Loss를 비교하여 현재 모델의 학습 상태를 진단할 수 있음.
과소적합 - 모델이 결과를 따라가지 못함
이상적인 상태
과적합 - 모델이 모든 결과를 억지로 지나가려는 모습

상태1: 과소적합
모델이 너무 단순하거나 학습 시간이 부족해 패턴을 담지 못한 상태.
Train loss와 Validation loss가 둘 다 높게 유지되며 떨어지지 않음

상태2: 과적합
모델이 데이터의 패턴이 아닌 문제를 통째로 암기해버린 상태를 의미함.
Train loss가 매우 낮지만, Validation loss는 높게 나옴. 



3. 과적합을 방지하는 방법

과적합과 일반화(Generalization)
과적합이 되면 새로운 데이터에 대해 적용하지 못하므로 실무 사용이 불가능한 모델임. 좋은 모델은 처음 보는 데이터에 대해서도 낮은 Loss를 보이는 일반화가 되어야함.

방법1: 조기 종료(Early stopping)
학습 과정 중 Validation loss가 감소하다가 다시 오르려는 순간이 과적합의 시작점임. 이 시점에서 학습을 강제로 종료하여 최적의 모델을 저장함.

방법2: 모델 경량화
모델의 파라미터 수가 너무 많으면 학습시 데이터의 불필요한 노이즈까지 외워버림. 
모델 파라미터 수를 줄여서 핵심 패턴만 학습하도록 유도함.

방법3: 가중치 규제(Weight regularization)
Loss 함수에 패널티 항을 추가하여 모델의 가중치 값이 너무 커지는 것을 방지함.
모델이 특정 데이터에 과도하게 집착하지 않도록 제약을 검.

방법4: 드롭아웃(Dropout)
학습 중 임의로 일부 뉴런을 비활성화하는 기법을 의미함.
특정 뉴런에 의존하는 것을 막고 네트워크 전체가 골고루 학습되도록 강제함.
마치 여러 개의 서로 다른 모델을 합쳐놓은 듯한 앙상블 효과를 냄.
