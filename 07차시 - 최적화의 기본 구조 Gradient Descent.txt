07차시 - 최적화의 기본 구조: Gradient Descent 이해



1. Loss와 기울기의 관계

학습의 목표: 최적의 파라미터 찾기
가장 작은 Loss를 가지는 최적의 파라미터를 찾는 것이 목표.
그러나 가능한 모든 파라미터 조합에 대한 손실을 계산하는 것은 불가능하기 때문에 한번에 최적 파라미터를 찾을 수 없음

기울기(Gradient)의 의미
모델의 파라미터를 업데이트 하기 위해서는 Loss 함수의 기울기 정보가 필요함.
전체 파라미터에 대한 Loss의 그래프는 알 수 없지만, 기울기를 통해 현재 모델의 파라미터에 대해서 Loss가 감소하는 방향을 알 수 있음

변화의 비율로서의 기울기
기울기는 파라미터가 아주 미세하게 변할 떄, Loss가 얼마나 변하는지를 나타냄.
-기울기가 크다: 파라미터를 조금만 바꿔도 Loss가 크게 변함
-기울기가 작다: 파라미터를 바꿔도 Loss의 변화가 적음
학습이 진행될수록 기울기가 작아지는게 일반적인 학습의 경향
Gradient = Loss의 변화량 / 파라미터의 변화량

기울기 계산 원리와 방법
복잡한 신경망의 모든 파라미터에 대해 기울기를 구하는 방법은 수학적 기술을 활용.
이에 앞서 파라미터를 업데이트하는 직관적 원리를 이해하는 것이 필요.

기울기 : 현재 위치에서 최저점으로 가는 방향을 알려주는 나침반. 나침반을 이용해 Loss의 최저점에 도달할 수 있음. 한번에 최저점으로 향하는게 아닌, 점진적으로 최저점에 다가감.



2. 경사하강법과 학습률의 관계

학습의 목표: 기울기를 이용해 Loss가 최소가 되는 파라미터 찾기
기울기는 Loss가 가장 빠르게 변화하는 방향과 그 변화율을 의미함.
이상적으로는 Loss가 최소가 되는 지점에서 기울기는 0이 됨
학습 목표는 기울기를 이용해 Loss를 감소시켜, 기울기가 0인 지점으로 수렴하는 것임

경사하강법(Gradient Descent)
경사하강법은 기울기를 활용하여 Loss를 줄이는 방향으로 파라미터를 업데이트함.
기울기의 반대 방향으로 이동해야하므로 마이너스 부호 사용
학습 목표는 Loss의 최저점을 찾는 것이기 때문에 기울기가 0에 인접하여 Loss가 충분히 작아질 때까지 파라미터 업데이트를 반복함

xnew =xcurrent − α∇f(xcurrent)
xcurrent : 현재 파라미터
xnew : 업데이트된 파라미터
α : 학습률 -> 하이퍼파라미터
f(xcurrent) : Loss 함수
∇f(xcurrent) : Loss 함수의 기울기

경사하강법의 시각화
평면은 파라미터에 대한 Loss 값을 나타내고, 점은 파라미터를 의미함. 
학습이 진행됨에 따라 Loss의 최저점으로 파라미터가 업데이트 됨
즉 오목한 평면으로 점이 모이는 모양을 띄게 됨.

학습률(Learning rate)
기울기를 통해 파라미터 업데이트 방향을 정한 다음 해당 방향으로 이동할 정도(보폭)를 결정. 이와 같이 업데이트 할 보폭의 크기를 결정하는 하이퍼파라미터(사람이 직접 설정하는 외부 변수, 모델이 학습하지 않는 파라미터)를 학습률이라고 함.

사례1: 학습률이 작을 때
문제점 1) 학습률이 작으면 Loss를 줄이는데 필요한 시간이 오래 걸리므로 비효율적임
문제점 2) Local minima(최적은 아니지만 기울기가 0인 구간)에 빠질 수 있음

사례 2: 학습률이 클 때
학습률이 크면 Loss가 최저점인 부분을 건너뛰어버릴 수 있음. Loss가 줄어들며 수렴하지 않고 발산할 수 있음
이러한 현상을 Overshooting이라고 함.

학습률 결정 방법
일반적으로 0.0001 수준의 작은 값으로 학습률을 설정함
모델의 크기나 파라미터 초기화 방법 등에 따라 최적의 학습률이 달라질 수 있음
(모델 구조, 모델 사이즈, 경사하강법 알고리즘, 파라미터 초기화 방법, 입력 데이터 스케일,  배치 크기 등)

하이퍼파라미터 결정
최적의 하이퍼파라미터를 결정하기 위해 크게 두가지 방법을 사용함
-그리드 탐색(Grid search) : 지정된 범위 내에서 일정 간격으로 최적의 하이퍼파라미터 조합을 찾음. 
장점: 최적의 조합을 확실하게 찾을 수 있음
-무작위 탐색(Random search) : 무작위로 하이퍼파라미터의 조합을 선택하여 최적의 조합을 찾음.
장점: 계산비용이 상대적으로 낮음

Loss 곡선과 정규화(Normalization)의 관계
데이터의 단위 차이가 크면 Loss 평면이 길게 늘어진 타원형이 되어 학습이 불안정해짐
정규화를 통해 데이터 스케일링을 맞춰 Loss 평면을 원형에 가깝게 만들면 빠르고 안정적인 학습이 가능함.
ex) 정규화 (X) : 키(170), 시력(0.1)		정규화(O) : 키(1.7), 시력(0.1)
