08차시 - 모델이 스스로 수정하는 방식: Backpropagation



1. 순전파와 역전파

순전파(Forward propagation)
입력 데이터와 모델 파라미터 간의 연산을 통해 출력이 만들어지는 과정
모델이 주어진 입력에 해당하는 문제를 풀고 답을 제출하는 단계에 해당함

입력정보 x -> 출력정보 f(x) = ReLU(wx +b)

역전파(Backpropagation)
모델의 출력을 바탕으로 계산된 정보를 출력층부터 입력층까지 전파하는 과정을 의미함. 모델이 틀린 문제를 복습하며 파라미터를 수정하는 단계에 해당함
예측값 <-> 정답
	     v
	<-학습

역전파가 필요한 이유
역전파는 Loss를 바탕으로 계산된 기울기를 모델 파라미터에 반영하는 과정임.



2. 연쇄 법칙을 통한 기울기 계산

깊은 신경망에서의 기울기 문제
출력층에 가까운 레이어의 파라미터는 미분을 통한 기울기 계산에 용이함
하지만 입력층에 가까운 레이어의 파라미터는 출력까지 여러 은닉층을 거치기 때문에 기울기 계산 또한 복잡함.
ex) Loss 계산 : J=f(w_outh)
w_out에 대한 기울기: ∂J/∂wout = ∂f(w_outh)/∂wout = f′(w_outh)h
h에 대한 기울기 = ??

연쇄법칙(Chain Rule)
깊은 레이어의 기울기를 계산하기 위해 합성함수의 미분 공식인 연쇄법칙을 사용함
복잡한 미분을 단계별 국소 미분들의 곱으로 분해하여 계산하는 방식을 의미함
ex)	L = L(y),  y = y(x)	=>  dL/dx = dL/dy · dy/dx

연쇄법칙의 예시
2개의 층으로 구성된 모델에 대한 기울기를 역순으로 계산하는 과정
ex) 	      f(W1x) 	     L(W2a1)
	x 	-> 	a1 	-> 	L

z1 = W1x
a1 = f(z1) > 은닉층의 출력(= 출력층의 입력)
z2 = W2a1 > 출력층에서 가중치를 곱한 결과
L = L(z2) > 최종 Loss

1) W2에 대한 기울기
 
∂L/∂W2 = ∂L/∂z2 · ∂z2/∂W2 = ∂L/∂z2 · a1

그럼 ∂L/∂z2 는 무엇인가?

"z₂가 아주 조금 변하면 Loss가 얼마나 변하는가?" 를 의미한다.
이를 흔히 출력층의 오차 또는 출력층에서 역전파되는 gradient 라고 부른다.
즉 "가중치의 변화량 = 출력층의 오차 × 그 가중치로 들어온 입력" 이라는 매우 직관적인 형태가 된다.

2) W1에 대한 기울기

∂L/∂W1 = ∂L/∂z2 · ∂z2/∂a1 · ∂a1/∂z1 · ∂z1/∂W1 = (∂L/∂z2 · W2 · f'(z1)) · x
			  =W2      =f'(z1)	     =x

결론적으로 출력에서 시작하여 입력으로 한단계 씩 이동하여 동일한 과정을 거쳐 미분을 곱해나가는 과정이다.

자동 미분 (Autograd)
딥러닝 프레임워크는 연쇄 법칙을 자동으로 수행하는 Autograd 기능을 제공함. 사용자가 복잡한 미분 공식을 직접 유도할 필요 없이 자동으로 기울기를 계산함
모델의 구조와 연산만 정리하면 프레임워크가 내부적으로 미분경로를 추적해줌.

계산 그래프(Computational Graph)의 흐름
계산 그래프를 통해 역전파를 효율적으로 처리함
-덧셈 노드 : 기울기를 그대로 전달
z = x + y
∂L/∂x = ∂L/∂z	∂L/∂y = ∂L/∂z
-곱셈 노드 : 입력값을 서로 바꾼 값을 곱하여 전달함
z = x · y
∂L/∂x = ∂L/∂z · y
∂L/∂y = ∂L/∂z · x

Detach의 역할
특정 레이어에 대해 역전파를 방지하고자 할 때 Detach를 사용함
주로 가중치를 고정하거나 특정 레이어를 학습에서 제외하고자 할 때 활용함.
