09차시 - Optimizer 선택 전략: SGD와 Adam 비교


1. 기본 경사하강법의 한계



옵티마이저(Optimizer)의 정의
경사하강법을 기반으로 모델의 학습단계에서 최적의 매개변수를 찾아내는 알고리즘
	 스텝방향 -> Momentum 	     |
SGD --|					      -> Adam
	 스텝크기 -> Adagrad -> RMSProp |

기본 경사하강법의 한계
경사하강법은 한 번의 업데이트를 위해 모든 학습 데이터에 대한 기울기를 계산해야함. 
데이터 규모가 클 경우 메모리 용량의 한계(Out of Memory; OOM)에 부딪힘.
데이터가 작을때에는 문제되지 않지만 현재에는 대용량의 데이터를 다루는 일이 많음.

SGD(Stochastic Gradient Descent)의 제안
메모리 문제를 해결하기 위해 전체 데이터를 작은 배치(Mini-Batch)로 나누어 학습함
한번의 학습 단계마다 일부 데이터만 사용하여 빠르게 방향을 결정하고 업데이트함

SGD의 한계 1: 불안정한 경로
일부 데이터만 보면 파라미터 업데이트 방향이 매번 달라짐
최적점을 향해 직선으로 가지 못하고 비틀거리며 이동하여 학습 시간이 오래 걸림
최종수렴까지의 시간을 지연시키는 주된 원인. 손실곡면이 길고 깊은 골짜기일때 두드러짐

SGD의 한계 2: 국소 최적점(Local minima)
경사가 0이 되는 지점에서 모델 업데이트 속도가 느려질 수 있음
이로 인해 전역 최소점(Global minima)이 아닌 국소 최소점(Local minima)에 갇힐 수 있음. 최적의 해를 찾지 못하고 국소 최소점에 갇히는 문제 발생.



2. 모멘텀 기반 Optimizer



관성(Momentum)의 도입
국소 최소점에서 벗어나기 위하여 물리학의 관성 개념을 도입함
기울기가 0이어도 이전에 내려오던 속도를 유지함으로써 골짜기를 넘어가게 함

관성으로 인한 학습 속도의 향상
관성을 활용하면 유사한 방향으로 이동하는 경우 가속도가 발생함
목적지를 향해 더욱 빠르게 이동할 수 있으며 Local minima에서 벗어날 수 있음

Momentum 옵티마이저
기존의 파라미터 업데이트 방향에 이전 업데이트 방향을 일정 수준 유지함
모멘텀(γ)은 이전 업데이트 방향성을 얼마나 유지할지 결정함(일반적으로 0.9로 설정)

v_t = γv_{t-1} - η∇J(θ_{t-1})
θ_t = θ_{t-1} + v_t

관성방향 v_{t-1}
가속된 방향 v_t
기울기 ∇J

적응형 학습률의 도입
기존 SGD는 모든 구간에서 동일한 학습률을 사용함
성능을 보다 향상시키기 위해 기울기에 따라 학습률을 조정하는 방식이 제안됨.
기존 SGD : θ_{t+1} = θ_t - η∇J(θ_t)

AdaGrad(Adaptive gradient)
기울기의 크기에 비례해서 학습률을 변경함
최소점 근처에서 기울기가 작아질 때 학습률을 키워 빠르게 수렴하도록 함
ε는 작은 양수로, 분모가 0이 되지 않게 함.

AdaGrad : θ_{t+1} = θ_t - (η / (√G_t + ε)) ⊙ ∇J(θ_t)
	      G_t = G_{t-1} + (∇J(θ_t))²

G_t는 과거 기울기 제곱의 누적합. 많이 학습된 파라미터는 G_t값이 커져 분모 증가, 실질적인 학습률이 작아짐. 이를 통해 학습 초기에는 빠르게 접근하고 최적점 근처에서는 정밀하게 탐색하는 효과를 얻음.

RMSProp(Root Mean Square Propagation)
AdaGrad에서 학습이 진행될수록 학습률이 너무 작아져서 멈추는 문제를 해결함.
지수이동평균(EMA)를 이용해 과거의 기울기 정보는 누적하되, 오래된 정보의 영향력은 줄이는 방식을 도입함

RMSProp : θ_{t+1} = θ_t - (η / √(G_t + ε)) ∇_θ J(θ_t) 
	       G_t = ρG_{t-1} + (1 - ρ)(∇_θ J(θ_t))²

Adam(Adaptive moment estimation)
관성과 학습률 조절의 장점을 결합한 알고리즘
방향은 관성을 따르되 이동 보폭은 상황에 맞춰 조절하는 주로 사용되는 방식 중 하나임.

Adam: 추가 메모리 사용량 + 하이퍼파라미터
SGD는 파라미터를 업데이트하기 위해서 현재의 기울기 정보만 있으면 되지만, Adam은 관성과 보폭 정보를 모든 파라미터마다 별도로 기억해야함. -> 메모리 증가
또한 각 정보에 대한 하이퍼파라미터(β₁, β₂)를 따로 지정해줘야 함.

Adam에서 추가된 메모리 : m_t, v_t
EMA에 의한 하이퍼파라미터 : β₁, β₂

m_t = β₁m_{t-1} + (1 - β₁)∇J(θ_t) 	# 1차 모멘트
v_t = β₂v_{t-1} + (1 - β₂)(∇J(θ_t))² 	# 2차 모멘트
θ_{t+1} = θ_t - (η / (√v̂_t + ε))m̂_t 	# 파라미터 업데이트
[m̂_t = m_t / (1 - β₁^t) , v̂_t = v_t / (1 - β₂^t)] 	# Bias Correction
