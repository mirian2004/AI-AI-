12차시 - 임베팅 모델 vs 생성 모델 : 역할과 차이



1. 검색과 생성



검색과 생성은 같은 문제인가?
생성형 AI가 검색, 요약, 답변 등의 작업을 하나의 모델로 처리하는 것처럼 보이나, 검색과 생성 과정에는 차이점이 있음

검색에 대한 질문 실험
동일한 질문을 생성형 AI를 활용해 두 가지 방법으로 처리해보기
1) 검색을 활용한 생성형 AI : 외부 정보 참고 후 답변
2) 검색을 활용하지 않은 생성형 AI : 모델이 스스로 답변 생성

검색에 대한 질문 실험 결과 예시
검색을 활용하지 않은 답변과 검색을 활용한 답변 모두 자연스럽게 보일 수 있으나, 정확도와 근거의 존재 여부 등에서 답변의 차이가 존재함.
검색을 활용한 답변 -> 정확도 높음, 근거 존재.



2. 임베딩 모델과 생성 모델



임베딩 모델이란
임베딩 모델은 입력 문장을 문장의 의미를 표현하는 벡터로 변환함.
문장의 길이나 형태와 무관하게 항상 고정된 길이의 숫자 배열이 나옴

임베딩 벡터
임베딩 벡터는 하나의 공간에 투영되며, 의미가 비슷한 문장일수록 벡터간 거리가 가까움. 단어가 달라도, 의미가 같으면 가까워질 수 있음

임베딩 모델의 역할
임베딩 모델은 답변을 직접 생성하지 않음
문장들은 임베딩 벡터로 변환하여 비교하고 어떤 문장이 더 비슷한지 판단.
임베딩 모델의 주된 목적은 "검색, 분류, 추천"

임베딩 모델을 활용하는 작업
-질문과 가장 비슷한 문서 찾기
-중복되거나 거의 같은 문장 제거
-사용자의 관심사와 가까운 콘텐트 추천
-공통점 기준으로 문서 묶기
=> 의미를 수치로 비교한다는 공통점 존재. 

생성 모델이란
생성 모델은 입력 텍스트를 바탕으로 다음에 올 토큰을 예측하며, 이 과정을 통해 문장을 생성하는 역할을 수행함.

생성 모델 작동 방식
한 단어가 정해지면 그 단어를 포함해 다시 다음 단어를 예측함
이 과정이 반복되며 자연스러운 문장이 생성됨

생성 모델을 활용하는 작업
-설명을 풀어서 말하기
-긴 문서 요약
-자연스러운 대화
-새로운 문장과 표현 생성
=> 정답이 하나로 고정되어있지 않다는 공통점 존재.

생성 모델의 한계
생성 모델은 정보를 저장하거나 정확한 검색을 하는 데에는 한게가 있음
-특정 정보를 정확히 찾아오는 역할에는 부적합
-검색을 활용하지 않은 생성 모델의 답변은 신뢰성이 낮을 수 있음

할루시네이션
생성형 AI가 사실이 아닌 정보나 존재하지 않는 내용을 마치 사실인 것처럼 그럴듯하게 만들어내는 '환각 현상'
확률적으로 가장 "그럴듯한" 답을 선택. 존재하지 않는 사실, 틀린 정보를 잘못 전달할 가능성이 있음.
생성형 모델을 단독으로 사용할 때 발생할 수 있는 가장 큰 리스크.

임베딩 모델 vs 생성 모델
검색 역할을 수행하는 임베딩 모델과 답변을 생성하는 생성 모델을 동시에 활용하여 신뢰성을 확보하면서 자연스러운 답변을 얻어낼 수 있음.



3. 임베딩 기반 검색

임베딩 기반 검색 실습
임베딩 모델이 검색을 어떻게 수행하는지 실습.
질의와 문서 모두 Embedding API로 벡터화
검색은 답을 생성하게 고르는 것이 아니라 "가장 가까운 벡터를 찾는" 과정.
결과는 "좌표 거리"로 결정



4. 생성 모델 비교



검색을 활용한 생성 모델과 활용하지 않은 생성 모델 비교
검색을 활요한 생성 모델과 검색을 활용하지 않은 생성 모델의 답변 비교해보기
검색을 활용하지 않은 생성 모델 : 웹 검색을 하지 않고 당신의 지식으로만 답변해주세요
검색을 활용한 생성 모델 : 웹 검색을 통해 최신 정보를 찾아서 답변해주세요.

1) 존재하지 않은 개념에 대해서 생성 요청하는 경우
검색 활용하지 않은 생성 모델 : 질문을 사실로 가정하고 가짜 설명을 참조하여 답변을 생성할 가능성 높음.
검색 활용한 생성 모델 : 사실 관계를 인지하고 답변의 왜곡을 방지

2) 특정 시점의 정보에 대한 검색 결과를 요청하는 경우
검색 활용하지 않은 생성 모델 : 과거의 데이터를 현재의 사실인 것처럼 말하거나 임의의 수치 제시
검색 활용한 생성 모델 : 당일의 공식 데이터를 직접 참조

3) 확정되지 않은 사실을 기정사실화한 질문
검색 활용하지 않은 생성 모델 : 확정된 사실로 오인하여 답변을 작성할 확률 존재
검색 활용한 생성 모델 : 검증된 자료를 기반으로 사실여부를 판단

4) 법률/정책의 미세한 수치 변경형
검색 활용하지 않은 생성 모델 : 구 버전의 정보를 현재의 것처럼 잘못 답변할 수 있음
검색 활용한 생성 모델 : 최신 정책 공고문을 참조하여 변경된 수치와 전년도 대비 차이점을 명확하게 비교하여 답변가능
