14차시 - 프롬프트와 확률 1 : 프롬프트는 확률 분포를 어떻게 형성할까?



1. LLM의 텍스트 생성 원리



LLM 답변의 다양성
Large Language Model(LLM)은 같은 내용의 명령어를 입력해도 입력 프롬프트를 어떻게 작성하는지에 따라 생성 결과가 달라지며, 같은 입력 프롬프트를 넣어도 다른 결과가 나오기도 함

LLM의 토큰 생성 원리
LLM은 토큰(Token)이라는 작은 조각을 하나씩 순차적으로 생성하여 문장을 완성함.
LLM은 토큰을 생성할 때 주어진 입력과 현재까지 생성된 텍스트를 바탕으로 다음에 올 여러 후보 토큰들에 대한 확률을 계산한 후, 확률에 따라 하나의 토큰을 선택함.
앞선 토큰 선택의 차이가 다음 입력 문맥을 변화시켜, 결과적으로 전혀 다른 답변을 생성함.

토큰 생성 확률을 조절하는 파라미터
파라미터를 조절하여 LLM의 답변 성향을 제어할 수 있으며 정확하고 논리적인 답변이 필요할 때는 보수적으로, 다양하고 창의적인 답변이 필요할 때는 모험적으로 토큰을 선택하도록 유도.
파라미터 종류 : Temperature, Top-k, Top-p		 

LLM 생성 파라미터 : Temperature
Temperature는 확률 분포의 선명도(Sharpness)를 조절함
값이 낮으면 확률이 높은 토큰이 더 압도적으로 선택되게 만들고(보수적),
값이 높으면 확률 차이를 줄여 다양한 토큰이 선택될 기회를 제공(창의성/무작위성)

LLM 생성 파라미터 : Top-k, Top-p
Top-k와 Top-p는 확률이 낮은 토큰들이 선택되지 않도록 후보군을 자르는 역할을 함.
Top-k는 등수로, Top-p는 누적 확률로 커트라인을 정해 안정적인 답변을 유도함.

즉 Temperature은 확률분포의 모양을, Top-k와 Top-p는 범위를 지정하는 역할.



2. 프롬프트 엔지니어링



파라미터 조절의 한계
파라미터 조절은 답변의 창의성이나 다양성을 바꿀 수는 있지만, 근본적인 답변의 품질이나 정확도를 보장하지는 않고 파라미터를 정교하게 튜닝해도 원하는 결과를 얻지 못할 수 있음. 파라미터 조절은 어디까지나 보조적인 역할이고, 프롬프트 입력에 크게 좌우됨.

프롬프트 엔지니어링
파라미터 설정만으로 원하는 답변을 얻기 어렵다면, 입력 프롬프트를 수정하여 결과를 개선할 수 있음. LLM으로부터 최상의 결과를 이끌어내기 위해, 입력하는 프롬프트를 전략적으로 설계하고 최적화하는 과정을 프롬프트 엔지니어링(Prompt Engineering)이라고 함.

프롬프트 작성 기본 원칙
LLM이 성능을 효과적으로 활용하기 위한 프롬프트 작성의 기본 원칙들이 존재함. 문제의 성격에 따라 적절한 전략을 선택하여 적용할 수 있음
1) 역할 부여 : 전문가나 특정 역할을 설정하여 답변을 최적화
2) 요구사항 구체화 : 모호함을 줄여 의도한 방향으로 답변 유도
3) 기호 활용 : 지시문에서 특정 단어 및 핵심 제약 사항을 강조
4) 예시 제공 : 모델에게 작업 방식과 출력 형식을 직접 보여줌
5) 사고 과정 유도 : 풀이 과정을 함꼐 생성하도록 유도

역할부여
LLM에서 "너는 AI 학과에 소속된 교수야"와 같이 구체적인 정체성(페르소나)을 입히는 기법임. 답변의 어조, 전문성 수준, 관점이 사용자의 의도에 맞춰 최적화됨.

요구사항 구체화
모델이 수행해야할 작업의 목표, 배경, 제약 조건 등을 명확히 명시해야 하고 이는 모델이 수많은 답변 가능성 중에서 사용자가 원하는 좁은 영역의 정답을 찾아가도록 돕는 역할을 함.

기호 활용
특정 단어 및 핵심 제약 사항을 강조하기 위해 특수 기호를 활용하는 기법임.
LLM이 지시 사항을 더욱 명확히 인지하여 복잡한 명령도 정확히 처리할 수 있도록 유도함

예시 제공 (Few-shot Prompting)
모델에게 문제와 정답의 쌍으로 된 예시(Shot)를 몇 가지 제공하고 모델은 이 예시를 통해 작업의 패턴과 원하는 출력 형식을 파악하여, 유사한 양식으로 답변하게 됨.

사고 과정 유도
복잡한 추론이나 산술 문제의 경우, 정답을 바로 요구하기보다 단계별로 생각하고 최종 결론 유도. 사고 과정을 명시적으로 생성함으로써 논리적 오류를 줄이고 정확도를 높이며, 오류 발생 원인을 쉽게 파악할 수 있음
