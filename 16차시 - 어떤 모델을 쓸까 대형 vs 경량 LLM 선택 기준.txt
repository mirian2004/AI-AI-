16차시 - 어떤 모델을 쓸까? 대형 vs 경량 LLM 선택 기준



1. 대형 LLM과 경량 LLM 이란?



LLM 파라미터
파라미터란(Parameter), AI가 방대한 데이터의 패턴을 학습하고 기억하기 위해 사용되는 매개변수임. LLM은 파라미터가 정교하게 조정되어 복잡한 언어적 맥락을 이해할 수 있음

모델 크기에 따른 응답 품질과 속도
LLM의 파라미터 수는 응답 속도와 답변 품질에 큰 영향을 미침
파라미터 수 증가 -> 답변 품질 증가, 연산의 수 기하급수적으로 증가, 토큰 당 latency(응답할때 걸리는 시간) 증가, 응답 속도 느림.

파라미터 수가 증가하면 복잡한 언어적 특성을 포착하여 추론 능력과 일반화 성능이 향상되지만, 이에 비례하여 연산량이 증가하므로 생성 속도는 저하됨.
대형 LLM : 생성 속도 느림. [추론, 감정, 상식, 창의, 문법, 논리, 뉘앙스]
경량 LLM : 생성 속도 빠름. 실시간 서비스에 적합 [추론, 감정, 상식]

모델의 연산은 메모리 상에서 수행되므로, 파라미터 수에 비례하여 필요한 메모리 용량도 증가함.
즉, 파라미터의 크기는 응답 속도와 답변의 품질 뿐만 아니라, 시스템 자원 규모에도 큰 영향을 미침.

LLM 활용에 필요한 메모리 용량은?
파라미터 관련 VRAM 용량 ≈ (파라미터 수 x 정밀도에 따른 파라미터 당 용량) x (1+여유 메모리)
ex) 파라미터 수: 80억개(8B), 정밀도:FP16(2 Bytes), 여유 메모리: 20% -> 필요 VRAM 용량 : 8 x 2 x 1.2 = 19.2GB

대형 LLM과 경량 LLM
파라미터 크기에 따른 LLM의 특징은 다음과 같이 요약할 수 있음
비교 항목				대형 LLM					경량 LLM
파라미터 크기	매우 많음. 수천억개 이상(70B~)		상대적으로 적음. 수십억개 이하(~8B)
성능			매우 우수. 복잡한 추론 가능.		보통. 단순 작업 수행에 적합
속도			느림						매우 빠름. 실시간 응답 가능
메모리		매우 높음. 고비용 서버 GPU 필요	비교적 적음. 일반 노트북/온디바이스 가능



2. LLM 선택 기준



LLM 선택 기준
모델을 활용하는 여러가지 상황에 따라 적합한 모델이 달라지며, 적합한 LLM을 선택하기 위해서는 "작업 난이도", "응답 속도에 대한 요구사항", "운영 환경"을 종합적으로 고려해야함.
ex) 작업 난이도 : 단순 요약, 복잡한 추론
응답 속도 : 실시간 챗봇, 보고서 작성
운영 환경 : 클라우드, 온디바이스  

LLM 선택 기준 - 작업 난이도
단순 작업 - 요약, 번역, 키워드 추출 등
-기초적인 언어 이해 능력으로 충분히 해결할 수 있는 작업.
-고도의 추론 능력이 필요하지 않기 때문에 경량 LLM을 사용하는 것이 효율적임.
복잡한 작업 - 창작, 코딩, 고난이도 수학 문제 등
-복합적인 문맥 파악과 정교한 논리력이 요구되는 작업.
-경량 모델의 제한된 파라미터로는 정확도를 보장하기 어렵기 때문에 대형 LLM이 효과적임.

LLM 선택 기준 - 응답 속도
실시간 처리 - 챗봇, 실시간 통번역, 음성 비서 등
-사용자의 대기 시간을 최소화해야 하며 즉각적인 상호작용이 필요한 작업.
-연산량이 적어 지연 시간이 짧은 경량 LLM이 적합함.
심층 분석 - 대규모 리포트 작성, 논문 분석 등
-응답 속도는 크게 중요하지 않으며, 결과물의 완성도와 논리적 깊이가 최우선인 작업.
-시간이 다소 소요되더라도 많은 자원을 활용해 좋은 결과를 생성하는 대형 LLM이 적절함.

LLM 선택 기준 - 운영 환경
On-Device 환경 - 노트북, 모바일 기기 등
-인터넷 없이 로컬 하드웨어 자원만으로 독립적인 구동이 필요한 환경.
-가용한 메모리와 연산 능력이 제한적이므로 최적화된 경량 LLM 사용이 필수적임.
클라우드/서버 환경 - API 활용, 고성능 GPU 서버 등
-고성능 GPU와 방대한 메모리 자원을 활용할 수 있는 환경.
-물리적 자원 한계를 고려하지 않고 최고 성능의 대형 LLM

LLM 선택의 추가 선택사항
LLM의 크기와 더불어, 다양한 추가적인 요소들을 선택할 수 있음.
모델 공급자, 모델 버전, 특화 능력 등.

LLM 선택의 추가 선택사항 - 모델 공급자
글로벌 AI 그룹에서 배포한 모델들은 수많은 사용자에게 검증되었으며, 일반적으로 우수한 성능을 보임.

LLM 선택의 추가 선택사항 - 모델 버전
일반적으로, 최근에 나온 모델들이 이전 모델들에 비해 뛰어난 성능을 보임

LLM 선택의 추가 선택사항 - 특화된 능력
특정 상황에서는 범용 모델보다 코딩, 수학, 금융, 의료 등 특정 작업에 특화된 모델이 효과적임.



3. 모델 선택 가이드라인 작성



모델 선택 가이드라인 작성
구체적인 모델 선택 가이드라인을 작성하며, 특정 문제 상황에서 LLM을 선정할 때 각 요소들을 어떻게 고려하면 좋을지 알아봄.
시나리오 1 - 여행용 실시간 통역 앱
시나리오 2 - 뉴스 스크랩 요약봇
시나리오 3 - 대규모 소송 법리 검토

모델 선택 가이드라인 작성 - 실시간 통역 서비스
시나리오 1 : 여행용 실시간 통역 앱 구축
-서비스 목표 : 여행지에서 현지인과 자연스러운 대화가 가능한 실시간 통역 서비스 구현
-활용 시나리오 분석 : 입력 문장의 구조가 단순하고 짧음, 고도의 논리적 추론보다는 단순 번역 능력이 요구됨.
-기술적 제약 사항 : 
네트워크 - 로밍이 원활하지 않은 환경을 고려하여, 인터넷 연결 없이 동작해야 함.
하드웨어 - 모바일 기기에서 제한된 배터리와 메모리 내에서 구동되어야 함
-핵심 기준 분석 :
작업 난이도 - 단순 회화 위주이므로 고성능 추론 모델이 불필요함
응답 속도 - 대화가 끊기지 않는 즉각적인 반응 속도가 필수적임
운영 환경 - 클라우드 접속이 불가하며, 기기 자체 연산이 필요함
종합 - 모바일 하드웨어의 메모리 및 배터리 제약을 충족하며, 네트워크 없이도 실시간 번역에 필요한 충분한 속도와 성능을 제공할 수 있는 LLM 선정이 필요함.
-최종 모델 : 경량 LLM(Gemma3-4B, Qwen3-4B, Gemini-3-Flash 등) 

모델 선택 가이드라인 작성 - 뉴스 요약
시나리오 2 : 뉴스 스크랩 요약 봇
-서비스 목표 : 매일 아침 특정 업계의 주요 뉴스를 수집하여, 임직원이 읽기 좋게 3줄로 요약 및 공유함
-활용 시나리오 분석 : 업무에 활용되는 자료이므로 핵심 내용 누락이 없어야함, 창의적인 글쓰기가 아닌 사실에 기반한 정보의 요약 능력이 요구됨, 사용자가 실시간으로 기다리는 것이 아니므로 즉각적인 응답이 필요 없음.
-기술적 제약 사항 : 
환경 - 사내 서버나 클라우드 환경에서 안정적인 전원과 인터넷 공급을 받음 
-핵심 기준 분석 :
작업 난이도 - 핵심 내용 및 문맥 파악 능력이 요구되나, 고난도 추론은 불필요함
응답 속도 - 사전에 처리 후 요약문 배포하면 되므로 중요도가 낮음
운영 환경 - 넉넉한 메모리 및 GPU 자원 활용 가능
종합 - 자원이 넉넉하므로 대형 LLM 활용에 문제가 없음. 다만, 대형 LLM을 사용할 만큼 어려운 작업이 아니기 때문에, 효율성을 고려한 LLM 선정이 필요함
-최종 모델 : 중형 LLM(Llama3-14B, Gemma3-21B, Mistral-Small3-24B 등)

모델 선택 가이드라인 작성 - 판례 분석
시나리오 3 : 대규모 소송 법리 검토
-서비스 목표 : 수천 페이지에 달하는 과거 판례와 소송 자료를 분석하여, 상대방 논리의 허점 찾아냄
-활용 시나리오 분석 : 전문적인 법률 용어와 복잡한 문장으로 구성된 방대한 양의 텍스트를 처리함, 단어의 표면적 의미를 넘어 판결문 이면에 숨겨진 논리적 인과관계를 파악해야 함, 분석에 며칠이 걸리더라도 정확한 결과가 중요하며 작은 오류가 패소로 이어질 수 있음.
-기술적 제약 사항 :
환경 - 매우 중요한 계약건으로, 최고 사양의 GPU 서버를 지원 받음
-핵심 기준 분석 :
작업 난이도 - 복잡한 법률 인과관계 파악과 고도의 추론 능력이 필수적임.
응답 속도 - 실시간성보다는 분석 결과의 완벽한 무결성과 정확도가 우선임
운영 환경 - 비용이나 장비 제약 없이, 최고 사양의 고성능 GPU 인프라 활용이 가능함.
종합 - 거대한 파라미터 크기에서 오는 최상급 논리 추론 능력을 활용하여, 수천 페이지의 문맥 속에서 법리적 모순을 완벽히 검증할 수 있는 LLM 선정이 필요함
-최종 모델 : 초대형 LLM(Llama3.1-405B, Qwen3-72B, GPT-5o 등)

모델 선택 가이드라인 작성 실습 - 코딩 어시스턴트
실습 : 지능형 코딩 어시스턴트 구축
-서비스 목표 : 개발자와 소통하며 실시간으로 코드를 완성하고 버그를 수정하는 'AI 프로그래머' 구현
-가이드라인 작성 필요 내용 : 활용 시나리오 분석, 기술적 제약 사항, 핵심 기준 분석, 최종 모델
 
Step 1. 핵심 3대 요소 분석
1) 작업 난이도 : 
-단순 작업 
-고난도 추론/논리

2) 응답 속도 :
-즉각적인 상호작용
-시간 소요 가능

3) 운영 환경
-온디바이스/오프라인
-고성능 GPU 서버

Step 2. 모델 크기 결정
1) 경량 LLM(~8B)
-하드웨어 제약이 큼
-빠른 속도가 중요

2) 중형 LLM(8B~32B)
-적절한 성능과 비용
-효율성 중요

3) 대형 LLM(32B~)
-운영 비용 무관
-최고 수준 정확도 필요

Step 3. 추가 선택 사항
1) 모델 공급자
-신뢰도 보장

2) 모델 버전 
-최신 모델 선택

3) 특화된 능력 (코딩 등)
-특정 도메인 전문성
